Đặt file nhạc thật (.mp3, .m4a, .ogg) tại đây, sau đó thêm id, title, artist (tùy chọn), src vào src/lib/wedding-playlist.ts.
Đường dẫn public bắt đầu bằng /music/. Không thêm bài nếu file chưa tồn tại.
Player phát sau thao tác mở thiệp, hỗ trợ chọn bài, trước/sau, âm lượng, tắt tiếng và lặp toàn bộ danh sách.
